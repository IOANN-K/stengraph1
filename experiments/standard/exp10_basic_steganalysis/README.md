# Експеримент 10

Базовий статистичний стегоаналіз стеганографії LSB.

## Початкові зображення

Аналізуються стего-зображення, згенеровані експериментом 09A.

Capacity levels:

- 10%
- 25%
- 50%
- 75%
- 90%
- 100%

Методи вбудовування:

- sequential
- pseudorandom
- adaptive

Початковий `input2.png` використовується як еталон контейнера.

## Статистичні показники

- LSB one/zero ratio
- binary LSB entropy
- статистика хі-квадрату Pair-of-Values
- normalized chi-square statistic
- chi-square p-value
- horizontal LSB agreement
- vertical LSB agreement

## Мета

Оцінити, чи спричиняє збільшення місткості вбудовування LSB статистично
виявні зміни, навіть коли візуальні показники якості зображення залишаються високими.

Цей експеримент є базовим статистичним стегоаналізом, а не повним
сучасним детектором стегоаналізу.

Запустіть `python3 scripts/run_experiment.py`, потім `python3 scripts/plot_results.py`. Високoентропійне вбудовування рандомізувало поведінку пар; адаптивний метод довше залишався подібним до контейнера за помірного навантаження. Частка/ентропія LSB самі по собі слабкі, великі вибірки дають дуже малі p-значення, а нормалізований хі-квадрат є описовим. Це реалізація, натхнена PoV, а не повне відтворення методу Westfeld–Pfitzmann.
