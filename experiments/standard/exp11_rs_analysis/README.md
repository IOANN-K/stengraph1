# Експеримент 11

RS-аналіз стеганографії LSB.

## Набір даних

Зображення-контейнер і стего-зображення, згенеровані експериментом 09A.

Capacity levels:

- 10%
- 25%
- 50%
- 75%
- 90%
- 100%

Methods:

- sequential
- pseudorandom
- adaptive

## RS-аналіз

Пікселі поділяються на групи по чотири.

Функція розрізнення:

f(x) = сума абсолютних різниць між сусідніми зразками.

Групи класифікуються як:

- Regular (R)
- Singular (S)
- Unusable (U)

для додатної маски M та оберненої маски -M.

Mask used:

`[1, 0, 1, 0]`

## Метрики

- R_m
- S_m
- R_-m
- S_-m
- R_m - S_m
- R_-m - S_-m

## Мета

Виміряти, як вбудовування LSB змінює статистику регулярних і сингулярних груп,
та порівняти виявність послідовного, випадкового й адаптивного розміщення.

Цей експеримент оцінює статистичну поведінку RS, але ще не визначає
точну довжину прихованого повідомлення.

Запустіть `python3 scripts/run_experiment.py`, потім `python3 scripts/plot_results.py`. Додатний RS-розрив наближався до нуля за майже повного вбудовування; адаптивний метод довше його зберігав. Обрізання від’ємних переворотів обмежує межі, тому це дослідницька реалізація RS, а не канонічне оцінювання в замкненій формі.
