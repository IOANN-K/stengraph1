# Experiment 10

Basic statistical steganalysis of LSB steganography.

## Source images

The stego images generated by Experiment 09A are analyzed.

Capacity levels:

- 10%
- 25%
- 50%
- 75%
- 90%
- 100%

Embedding methods:

- sequential
- pseudorandom
- adaptive

The original `input2.png` is used as the cover reference.

## Statistical measures

- LSB one/zero ratio
- binary LSB entropy
- Pair-of-Values chi-square statistic
- normalized chi-square statistic
- chi-square p-value
- horizontal LSB agreement
- vertical LSB agreement

## Goal

Evaluate whether increasing LSB embedding capacity produces statistically
detectable changes even when visual image-quality metrics remain high.

This experiment represents basic statistical steganalysis rather than a
complete modern steganalysis detector.

Run `python3 scripts/run_experiment.py`, then `python3 scripts/plot_results.py`. High-entropy embedding randomized pair behavior; adaptive remained cover-like longer at moderate load. LSB ratio/entropy are weak alone, large samples drive tiny p-values, and normalized chi-square is descriptive. This is PoV-inspired, not a complete Westfeld–Pfitzmann reproduction.
