# Experiment 11

RS analysis of LSB steganography.

## Dataset

The cover image and stego images generated by Experiment 09A.

Capacity levels:

- 10%
- 25%
- 50%
- 75%
- 90%
- 100%

Methods:

- sequential
- pseudorandom
- adaptive

## RS analysis

Pixels are divided into groups of four.

Discrimination function:

f(x) = sum of absolute differences between adjacent samples.

Groups are classified as:

- Regular (R)
- Singular (S)
- Unusable (U)

for both a positive mask M and inverse mask -M.

Mask used:

`[1, 0, 1, 0]`

## Metrics

- R_m
- S_m
- R_-m
- S_-m
- R_m - S_m
- R_-m - S_-m

## Goal

Measure how LSB embedding changes regular and singular group statistics,
and compare detectability between sequential, random and adaptive placement.

This experiment evaluates RS statistical behavior but does not yet estimate
the exact hidden-message length.

Run `python3 scripts/run_experiment.py`, then `python3 scripts/plot_results.py`. The positive RS gap approached zero near full embedding; adaptive retained it longer. Negative flipping clips boundaries, so this is an exploratory RS implementation, not canonical closed-form estimation.
